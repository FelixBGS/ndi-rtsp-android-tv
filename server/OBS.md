# OBS + DistroAV: NDI / захват экрана -> MediaMTX

Самый простой вариант для Windows/macOS: OBS принимает NDI (или захватывает экран/камеру),
кодирует поток один раз и отправляет его в MediaMTX по RTMP. Телевизоры забирают его по RTSP.

## Установка

1. [OBS Studio](https://obsproject.com/) 30+.
2. [NDI Runtime / NDI Tools](https://ndi.video/tools/).
3. Плагин [DistroAV](https://github.com/DistroAV/DistroAV) (бывший obs-ndi).
4. MediaMTX, запущенный с конфигом [`mediamtx.yml`](mediamtx.yml).

## Источник

- NDI: «Источники» -> «+» -> **NDI Source** -> выбрать камеру/ПК в сети.
- Экран: **Захват экрана** (Display Capture) или **Захват окна**.
- Камера: **Устройство захвата видео**.

## Настройки трансляции

«Настройки» -> «Трансляция»:

| Поле | Значение |
|------|----------|
| Сервис | Пользовательский |
| Сервер | `rtmp://127.0.0.1:1935` (или IP машины с MediaMTX) |
| Ключ потока | `live` |

## Настройки вывода (важно для задержки)

«Настройки» -> «Вывод» -> режим вывода **Расширенный** -> «Потоковое вещание»:

| Параметр | Значение | Зачем |
|----------|----------|-------|
| Кодировщик | NVENC H.264 / QuickSync H.264 / x264 | Аппаратный, если есть |
| Управление битрейтом | CBR | Ровная нагрузка на сеть |
| Битрейт | 4000-8000 Kbps для 1080p30 | Сеть: битрейт x число ТВ |
| Интервал ключевых кадров | 1 s | ТВ подключается не дольше, чем через 1 с |
| Профиль | main (или high) | Поддерживается всеми приставками |
| B-кадры (NVENC: Max B-frames) | 0 | Минус задержка декодера |
| x264: Tune | zerolatency | |
| x264: опции | `bframes=0` | |
| NVENC: Preset/Tuning | P1-P3 / Low Latency (или Ultra Low Latency) | |

«Настройки» -> «Видео»: выходное разрешение 1920x1080, 30 FPS (60 FPS только если приставки
стабильно его тянут).

«Настройки» -> «Дополнительно» -> «Сеть»: включить **«Режим низкой задержки»**.

## Запуск

Нажать **«Начать трансляцию»**. Проверить на ПК:

```bash
ffplay -fflags nobuffer -flags low_delay -rtsp_transport tcp rtsp://127.0.0.1:8554/live
```

или в VLC: «Медиа» -> «Открыть URL» -> `rtsp://<IP сервера>:8554/live`.

Для работы без участия человека в OBS есть ключ запуска `--startstreaming`
(можно добавить в автозагрузку вместе с MediaMTX).
